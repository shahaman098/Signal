# System Overview

## L4: Universal Principle

Creative teams need evidence-backed automation, not another disconnected inspiration tool.

## L3: Abstract Framework

Separate interface, API control, and model-backed reasoning so the product can evolve without coupling UX directly to provider logic.

## L2: Applicable Mechanism

Fetch live owned and competitor creative data, derive fatigue and saturation signals, then ground a Qwen brief in those signals before a human operator approves handoff.

## L1: Concrete Implementation

Expose a Next.js dashboard over a small Express API that proxies to a live creative intelligence backend and packages the API for Alibaba Cloud container deployment.
